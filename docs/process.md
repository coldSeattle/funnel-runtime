# Процесс работы с AI-агентами

Журнал того, как задача была декомпозирована, что делали агенты параллельно, что
проверялось и отклонялось. Дополняется по ходу работы.

## Инструменты
- Claude Code (Opus) — основной агент: дизайн, план, интеграция, ревью, деплой.
- Субагенты Claude Code — параллельная реализация независимых частей по контракту из
  `docs/design.md`. Роли описаны в `.claude/agents/`.
- `CLAUDE.md` — память проекта: стек, команды, инварианты, границы владения папками.
  Агенты не перечитывают всё задание каждый раз и не нарушают чужие зоны.
